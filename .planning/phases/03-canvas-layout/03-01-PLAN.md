<objective>
Implement SUPER+mouse drag and resize for canvas windows, completing window interaction on the infinite canvas.

Purpose: Phase 2 created CCanvasLayout with window positioning and viewport transforms, but the base IHyprLayout drag/resize logic assumes floating windows and screen-space coordinates. Canvas windows are "tiled" and live in canvas coordinates, so drag/resize must be overridden to: (1) skip the floating-window checks, (2) convert screen-space mouse deltas to canvas-space by dividing by viewport scale.

Output: CCanvasLayout with working SUPER+left-click drag and SUPER+right-click resize at any zoom level.

Implement in CanvasLayout.cpp:

**onBeginDragWindow():** Simplified version that does NOT call updateDragWindow (which would try to float the tiled window). Instead:
- Get DRAGGINGWINDOW from g_pInputManager->m_currentlyDraggedWindow
- Validate with validMapped
- Store m_beginDragXY = g_pInputManager->getMouseCoordsInternal()
- Store m_canvasDragStartPos = DRAGGINGWINDOW->m_realPosition->goal()
- Store m_canvasDragStartSize = DRAGGINGWINDOW->m_realSize->goal()
- Store m_lastMousePos = m_beginDragXY
- Set m_beginDragSizeXY = m_canvasDragStartSize (needed for corner detection)
- Set m_beginDragPositionXY = g_pCanvasViewport->canvasToScreen(m_canvasDragStartPos) (screen coords for corner detection)
- Determine m_grabbedCorner based on mouse position relative to window screen box (same quadrant logic as base class)
- Set cursor image: "grabbing" for move, directional resize cursor for resize
- Focus and raise the window via g_pCompositor->focusWindow / changeWindowZOrder
- Damage the window

**onMouseMove(const Vector2D& mousePos):** Canvas-aware drag/resize:
- Get DRAGGINGWINDOW, validate
- Compute DELTA = mousePos - m_beginDragXY (screen pixels)
- Compute canvasDelta = DELTA / g_pCanvasViewport->scale()
- For MBIND_MOVE:
  - newPos = m_canvasDragStartPos + canvasDelta
  - Set m_realPosition->setValueAndWarp(newPos) and m_position = newPos
- For MBIND_RESIZE / MBIND_RESIZE_FORCE_RATIO / MBIND_RESIZE_BLOCK_RATIO:
  - Compute newSize based on m_grabbedCorner and canvasDelta (same corner logic as base)
  - Clamp to minimum 200x150
  - Compute newPos adjustment for top-left/top-right/bottom-left corners
  - Set m_realSize->setValueAndWarp(newSize), m_size = newSize
  - Set m_realPosition->setValueAndWarp(newPos), m_position = newPos
  - Call DRAGGINGWINDOW->sendWindowSize() to notify client
- m_lastMousePos = mousePos
- Damage all monitors via g_pCanvasViewport->damageAllMonitors()

**onEndDragWindow():** Simple cleanup:
- Unset cursor image via g_pInputManager->unsetCursorImage()
- Reset g_pInputManager->m_currentlyDraggedWindow
- Set g_pInputManager->m_wasDraggingWindow = true

**moveActiveWindow(delta, pWindow):** For programmatic moves (keybind dispatchers):
- Get window (pWindow or m_lastWindow)
- Validate
- Convert delta to canvas space: canvasDelta = delta / g_pCanvasViewport->scale()
- Update m_position += canvasDelta, m_realPosition->setValueAndWarp(m_position)
- Damage

**resizeActiveWindow:** Update existing implementation to scale delta:
```cpp
void CCanvasLayout::resizeActiveWindow(const Vector2D& delta, eRectCorner, PHLWINDOW pWindow) {
    if (!pWindow)
        return;
    const auto canvasDelta = delta / g_pCanvasViewport->scale();
    const auto MIN_SIZE = Vector2D{200, 150};
    auto newSize = (pWindow->m_size + canvasDelta).clamp(MIN_SIZE);
    pWindow->m_size = newSize;
    pWindow->m_realSize->setValueAndWarp(newSize);
    pWindow->sendWindowSize();
    g_pCanvasViewport->damageAllMonitors();
}
```

Do NOT use animations (setValueAndWarp, not operator=) — canvas drag should be immediate, not animated. This avoids lag at low zoom levels where small screen deltas map to large canvas movements.
