<task type="auto">
  <name>Task 1: Add visibility culling to window rendering and annotation rendering</name>
  <files>src/render/Renderer.cpp, src/canvas/CanvasAnnotation.cpp</files>
  <action>
In Renderer.cpp, find the canvas window rendering loop (where it iterates layout windows and calls renderWindow or similar). Before rendering each window:
1. Compute the window's screen-space box: `auto screenBox = g_pCanvasViewport->canvasToScreen(CBox{window->m_position, window->m_size});`
2. Check if screenBox intersects with the monitor's box: `CBox monitorBox = {pMonitor->m_position, pMonitor->m_size};`
3. If no intersection (screenBox.x + screenBox.w < monitorBox.x || screenBox.x > monitorBox.x + monitorBox.w || screenBox.y + screenBox.h < monitorBox.y || screenBox.y > monitorBox.y + monitorBox.h), skip rendering with `continue;`

Create a free function `isBoxVisible(const CBox& screenBox, const CBox& monitorBox)` at top of file for the intersection test. Return true if boxes overlap.

In CanvasAnnotation.cpp render method:
1. Compute visible canvas-space bounds from monitor: get monitor rect, convert corners to canvas space via screenToCanvas
2. Before rendering each stroke: check if any point falls within visible bounds (with thickness margin). Skip if entirely outside.
3. Before rendering each arrow: check if start or end point is within visible bounds (with margin). Skip if both outside.
4. Before rendering each sticky note: check if note box intersects visible bounds. Skip if outside.
5. Before rendering each text: check if text position is within visible bounds (with generous margin for text width). Skip if outside.

Use a helper `isInVisibleBounds(const Vector2D& point, const CBox& visibleCanvas, double margin)` for point-in-rect with margin.

For strokes, check bounding box of all points rather than each individual point (compute min/max x/y of stroke points, check that bounding box against visible canvas bounds).
