  <name>Task 1: Create command interface, concrete commands, and undo/redo stack</name>
  <files>src/canvas/CanvasCommand.hpp, src/canvas/CanvasCommand.cpp, src/canvas/CanvasUndoRedo.hpp, src/canvas/CanvasUndoRedo.cpp</files>
  <action>
Create CanvasCommand.hpp with:
- `class ICanvasCommand` with pure virtual `void execute()`, `void undo()`, virtual destructor
- Concrete commands (each stores before/after state):
  - `WindowMoveCommand(PHLWINDOWREF window, Vector2D oldPos, Vector2D newPos)` — undo sets position back to oldPos via m_realPosition->setValueAndWarp + m_position, calls damageAllMonitors and persistence trackWindow/scheduleSave
  - `WindowResizeCommand(PHLWINDOWREF window, Vector2D oldPos, Vector2D oldSize, Vector2D newPos, Vector2D newSize)` — same pattern, also calls sendWindowSize
  - `AnnotationAddCommand(std::string type, uint64_t id, std::variant<SAnnotationStroke, SAnnotationArrow, SAnnotationStickyNote, SAnnotationText> data)` — undo removes by id, execute re-adds from stored data. Type string is "stroke"/"arrow"/"sticky"/"text"
  - `AnnotationRemoveCommand` — inverse of Add (stores the removed element, undo re-adds it)
  - `AnnotationClearCommand(std::vector<SAnnotationStroke> strokes, std::vector<SAnnotationArrow> arrows, std::vector<SAnnotationStickyNote> notes, std::vector<SAnnotationText> texts)` — stores all annotations before clear, undo restores them all

Create CanvasUndoRedo.hpp/cpp with:
- `class CCanvasUndoRedo` with `void push(UP<ICanvasCommand> cmd)`, `void undo()`, `void redo()`
- Two stacks: `std::vector<UP<ICanvasCommand>> m_undoStack, m_redoStack`
- `push()` adds to undo stack, clears redo stack, enforces MAX_STACK_SIZE = 100 (pop front if exceeded)
- `undo()` pops from undo, calls cmd->undo(), pushes to redo
- `redo()` pops from redo, calls cmd->execute(), pushes to undo
- Global: `inline UP<CCanvasUndoRedo> g_pCanvasUndoRedo;`

For AnnotationAddCommand execute/undo, use g_pCanvasAnnotation add/remove methods. After every execute/undo call markDirty() and damageAllMonitors().

For AnnotationClearCommand undo, iterate stored vectors and re-add each element. Execute calls clearAll().

Include CanvasPersistence.hpp in CanvasCommand.cpp for window commands to call trackWindow/scheduleSave after position/size changes.
