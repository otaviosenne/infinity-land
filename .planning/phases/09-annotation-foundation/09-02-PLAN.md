<task type="auto">
  <name>Task 1: Toolbar rendering and click handling</name>
  <files>src/canvas/CanvasToolbar.hpp, src/canvas/CanvasToolbar.cpp</files>
  <action>
Create a Cairo-rendered toolbar overlay for draw mode.

**CanvasToolbar.hpp:**
- Struct `SToolbarButton`: `CBox box` (screen-space), `enum eButtonType { BTN_TOOL_BRUSH, BTN_TOOL_ERASER, BTN_COLOR, BTN_THICKNESS }`, `CHyprColor color` (for color buttons), `float thickness` (for thickness buttons), `eDrawTool tool` (for tool buttons)
- Class `CCanvasToolbar`:
  - `void render(PHLMONITOR pMonitor, const CRegion& damage)` — renders toolbar texture
  - `bool handleClick(const Vector2D& screenPos)` — returns true if click was on toolbar
  - `bool containsPoint(const Vector2D& screenPos) const` — hit test for toolbar area
- Private: `SP<CTexture> m_texture`, `bool m_dirty = true`, `std::vector<SToolbarButton> m_buttons`, `CBox m_bounds`
- Constants: `TOOLBAR_MARGIN = 16`, `BUTTON_SIZE = 32`, `BUTTON_GAP = 6`, `TOOLBAR_PADDING = 8`
- Color palette (8 colors): red (1,0.3,0.3), orange (1,0.6,0.2), yellow (1,0.9,0.2), green (0.3,0.8,0.3), blue (0.3,0.5,1), purple (0.7,0.3,1), white (1,1,1), black (0.1,0.1,0.1) — all alpha 1.0
- Global: `inline UP<CCanvasToolbar> g_pCanvasToolbar;`

**CanvasToolbar.cpp:**
- `render()`:
  1. Only render if g_pCanvasDrawMode->isActive()
  2. Compute toolbar layout: horizontal bar in bottom-right. Layout order left-to-right: [brush][eraser] | [8 colors] | [thin][medium][thick]
  3. Total width = TOOLBAR_PADDING*2 + (2 tool + 8 color + 3 thickness) * BUTTON_SIZE + 12 * BUTTON_GAP + 2 separator gaps (16px each)
  4. Position: bottom-right corner minus TOOLBAR_MARGIN, above the minimap if it exists (use Y = monitorH - TOOLBAR_MARGIN - BUTTON_SIZE - TOOLBAR_PADDING*2 - 140 to clear minimap space)
  5. Build m_buttons vector with screen-space CBox for each button
  6. Create Cairo surface sized to toolbar dimensions
  7. Draw background: rounded rect (radius 8), color (0.15, 0.15, 0.15, 0.85)
  8. For each button: draw rounded rect (radius 4). Tool buttons: light gray fill, active tool gets white border (2px). Color buttons: fill with the color, active color gets white border. Thickness buttons: draw a horizontal line at the button center with the respective thickness (2, 4, 8), active thickness gets white border
  9. Draw separator lines (1px, rgba 0.4,0.4,0.4,0.5) between sections
  10. Upload to GL texture (same Cairo->GL pattern), render at toolbar position
  11. Destroy Cairo resources

- `handleClick(screenPos)`:
  1. Check if screenPos is within m_bounds, return false if not
  2. Find which button contains the click point
  3. BTN_TOOL_BRUSH/BTN_TOOL_ERASER: call g_pCanvasDrawMode->setTool(...)
  4. BTN_COLOR: call g_pCanvasDrawMode->setColor(button.color)
  5. BTN_THICKNESS: call g_pCanvasDrawMode->setThickness(button.thickness)
  6. Set m_dirty = true, damageAllMonitors
  7. Return true

- `containsPoint(screenPos)`: return screenPos within m_bounds
