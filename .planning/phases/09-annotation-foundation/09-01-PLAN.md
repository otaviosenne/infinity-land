<task type="auto">
  <name>Task 1: Annotation data model and Cairo rendering</name>
  <files>src/canvas/CanvasAnnotation.hpp, src/canvas/CanvasAnnotation.cpp</files>
  <action>
Create the annotation data model and Cairo-to-GL rendering pipeline.

**CanvasAnnotation.hpp:**
- Define `SAnnotationStroke` struct: `std::vector<Vector2D> points` (canvas-space), `CHyprColor color`, `float thickness`, `uint64_t id` (auto-increment counter)
- Define `CCanvasAnnotation` class with:
  - `void addStroke(SAnnotationStroke stroke)` — adds to m_strokes vector
  - `void removeStroke(uint64_t id)` — removes by id
  - `SAnnotationStroke* findNearestStroke(const Vector2D& canvasPos, double threshold)` — returns stroke within threshold distance, nullptr if none (for eraser object mode)
  - `void render(PHLMONITOR pMonitor, const CRegion& damage)` — renders all strokes to Cairo surface, uploads as GL texture, draws with renderTexture
  - `void markDirty()` — forces re-render of Cairo surface next frame
  - `const std::vector<SAnnotationStroke>& strokes() const`
- Private members: `std::vector<SAnnotationStroke> m_strokes`, `SP<CTexture> m_texture`, `bool m_dirty = true`, `uint64_t m_nextId = 1`, `int m_lastWidth = 0`, `int m_lastHeight = 0`
- Global: `inline UP<CCanvasAnnotation> g_pCanvasAnnotation;`

**CanvasAnnotation.cpp:**
- `render()` implementation:
  1. Get monitor size for surface dimensions
  2. If not dirty and texture exists and size unchanged, just render existing texture
  3. Create cairo_image_surface_create(CAIRO_FORMAT_ARGB32, monitorW, monitorH)
  4. Clear surface to transparent (cairo_set_operator CAIRO_OPERATOR_CLEAR, paint, then set back to CAIRO_OPERATOR_OVER)
  5. For each stroke: set color with cairo_set_source_rgba, set line width (stroke.thickness * viewport scale), set line cap CAIRO_LINE_CAP_ROUND, set line join CAIRO_LINE_JOIN_ROUND
  6. For each point in stroke: convert from canvas-space to screen-space using g_pCanvasViewport->canvasToScreen, subtract monitor position, then cairo_line_to (first point: cairo_move_to)
  7. cairo_stroke()
  8. Flush surface, upload to GL texture using the same pattern as renderText: allocate, bind, set SWIZZLE_R=BLUE and SWIZZLE_B=RED, glTexImage2D
  9. Render texture at full monitor box using g_pHyprOpenGL->renderTexture with alpha=1.0
  10. Destroy cairo surface/context
  11. Set m_dirty = false
- `findNearestStroke()`: For each stroke, compute minimum distance from canvasPos to any line segment in the stroke. Return the stroke with smallest distance if under threshold (default 20.0 canvas units).
- Distance from point to line segment: standard projection formula (project point onto segment, clamp parameter to [0,1], compute distance to projected point)

- Global: `inline UP<CCanvasDrawMode> g_pCanvasDrawMode;`

**CanvasDrawMode.cpp:**
- `handleMouseButton(screenPos, pressed)`:
  - If not active, return false
  - Convert screenPos to canvas space via g_pCanvasViewport->screenToCanvas
  - BRUSH tool + pressed: start new stroke (clear m_currentStroke points, set color/thickness from active settings, add first point, set m_drawing=true)
  - BRUSH tool + released: if m_drawing and stroke has >=2 points, call g_pCanvasAnnotation->addStroke(m_currentStroke), markDirty, damageAllMonitors. Set m_drawing=false
  - ERASER tool + pressed: call g_pCanvasAnnotation->findNearestStroke(canvasPos, 20.0). If found, removeStroke(id), markDirty, damageAllMonitors
  - Return true (consumed)
- `handleMouseMove(screenPos)`:
  - If not active, return false
  - If m_drawing (brush active): convert to canvas, add point to m_currentStroke.points, markDirty on g_pCanvasAnnotation, damageAllMonitors. Return true
  - If eraser and button held: same as eraser press (continuous erasing). But simpler: just return true to consume move events
  - Return true (consume all mouse moves in draw mode)
