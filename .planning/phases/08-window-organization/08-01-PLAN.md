  <action>
Create src/layout/CanvasSnap.hpp and .cpp with two free functions:

1. `Vector2D resolveOverlap(const Vector2D& droppedPos, const Vector2D& droppedSize, const std::vector<CBox>& otherWindows)` — Given the dropped window's position/size and bounding boxes of all other windows, return adjusted position using minimum translation vector. For each overlapping window, compute push distance in all 4 directions (left, right, up, down), pick direction with smallest displacement. Iterate until no overlaps remain (max 10 iterations to prevent infinite loops). If no overlap, return droppedPos unchanged.

2. `std::vector<Vector2D> computeGridLayout(int windowCount, const Vector2D& viewportCenter, const Vector2D& viewportSize, const Vector2D& cellSize)` — Return a vector of positions arranging windowCount items in a grid centered on viewportCenter. Compute columns as ceil(sqrt(windowCount)), rows as ceil(windowCount/columns). Gap between cells: 20 canvas units. Each position is the top-left of a cell.

Include guard: `#pragma once`. Include `../defines.hpp` and `<vector>`.

Static constexpr int OVERLAP_MAX_ITERATIONS = 10 and double GRID_GAP = 20.0 in the .cpp.
