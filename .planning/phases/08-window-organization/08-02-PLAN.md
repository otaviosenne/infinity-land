  <name>Task 1: Create CanvasTags and CanvasViews modules</name>
  <files>src/canvas/CanvasTags.hpp, src/canvas/CanvasTags.cpp, src/canvas/CanvasViews.hpp, src/canvas/CanvasViews.cpp</files>
  <action>
**CanvasTags.hpp/.cpp:**

Class `CCanvasTags` with:
- `void setTag(PHLWINDOW window, const std::string& colorName)` — store tag by window address (use `std::format("{}", (uintptr_t)window.get())` as key)
- `std::string getTag(PHLWINDOW window) const` — return color name or empty string
- `void removeTag(PHLWINDOW window)`
- `nlohmann::json toJson() const` — serialize all tags as JSON object mapping window-class+position-hash to color name (for persistence — use appClass as key since addresses change across restarts)
- `void fromJson(const nlohmann::json& j)` — deserialize

Private: `std::unordered_map<std::string, std::string> m_tags` (key = window address string, value = color name).

Color palette as a static map: "red" -> 0xFF4444FF, "green" -> 0x44FF44FF, "blue" -> 0x4488FFFF, "yellow" -> 0xFFFF44FF, "purple" -> 0xAA44FFFF, "orange" -> 0xFF8844FF. Provide `static uint32_t colorToRGBA(const std::string& name)`.

Global: `inline UP<CCanvasTags> g_pCanvasTags;`

**CanvasViews.hpp/.cpp:**

Class `CCanvasViews` with:
- `void createView(const std::string& name)` — create named view, starts with all current windows included
- `void switchView(const std::string& name)` — set active view, hide windows not in view, show windows in view
- `void addToView(const std::string& viewName, PHLWINDOW window)` — add window to a view by appClass
- `void removeFromView(const std::string& viewName, PHLWINDOW window)`
- `std::string activeView() const` — return current view name ("all" default)
- `bool isWindowVisible(PHLWINDOW window) const` — true if window is in active view or active view is "all"
- `nlohmann::json toJson() const` / `void fromJson(const nlohmann::json& j)`

Private: `std::unordered_map<std::string, std::vector<std::string>> m_views` (view name -> list of appClasses), `std::string m_activeView = "all"`.

When switching views, iterate all layout windows: if not in view, call `window->setHidden(true)`; if in view, call `window->setHidden(false)`. Call `g_pCanvasViewport->damageAllMonitors()`.

Global: `inline UP<CCanvasViews> g_pCanvasViews;`
