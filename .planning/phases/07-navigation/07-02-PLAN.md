**src/canvas/CanvasQuickJump.hpp:**
```cpp
#pragma once
#include "../defines.hpp"
#include "../helpers/Monitor.hpp"

struct SQuickJumpMatch {
    PHLWINDOWREF window;
    std::string  title;
    std::string  appClass;
    int          score;
};

class CCanvasQuickJump {
  public:
    void render(PHLMONITOR pMonitor, const CRegion& damage);
    void toggle();
    void close();
    bool isActive() const;
    bool handleKey(uint32_t keycode, bool pressed);

  private:
    bool        m_active = false;
    std::string m_query;
    int         m_selectedIndex = 0;
    std::vector<SQuickJumpMatch> m_matches;

    void updateMatches();
    int  fuzzyScore(const std::string& query, const std::string& target) const;
    void jumpToSelected();

    static constexpr int OVERLAY_WIDTH  = 400;
    static constexpr int OVERLAY_HEIGHT = 40;
    static constexpr int MATCH_HEIGHT   = 32;
    static constexpr int MAX_MATCHES    = 5;
};

inline UP<CCanvasQuickJump> g_pCanvasQuickJump;
```

**src/canvas/CanvasQuickJump.cpp:**

`toggle()`: flip m_active. If activating: clear m_query, m_selectedIndex=0, call updateMatches(). Call g_pCanvasViewport->damageAllMonitors().

`close()`: m_active = false, damage.

`isActive()`: return m_active.

`fuzzyScore(query, target)`:
- Case-insensitive substring match. Return -1 if no match.
- Score = position of match (earlier = higher score, so negate position). Exact prefix match gets bonus +100.
- Simple approach: convert both to lowercase, use std::string::find. If found at pos 0: return 100. If found: return 50 - pos. Else: return -1.

`updateMatches()`:
- Clear m_matches
- For each window in g_pCompositor->m_windows: skip hidden/unmapped
- Get title from `w->m_title` and class from `w->m_class`
- If m_query is empty, add all windows with score=0
- Otherwise compute fuzzyScore against both title and class, take max
- If score >= 0, add to m_matches
- Sort m_matches by score descending
- Clamp m_selectedIndex to [0, m_matches.size()-1]

`handleKey(keycode, pressed)`:
- If not m_active or not pressed, return false
- KEY_ESCAPE (1): close(), return true
- KEY_ENTER (28): jumpToSelected(), close(), return true
- KEY_UP (103): m_selectedIndex = max(0, m_selectedIndex-1), damage, return true
- KEY_DOWN (108): m_selectedIndex = min(m_matches.size()-1, m_selectedIndex+1), damage, return true
- KEY_BACKSPACE (14): if !m_query.empty(), pop_back, updateMatches(), damage, return true
- For letter/number keys (mapped via xkb or simple range check 2-53 roughly): append character to m_query. Use `xkb_state_key_get_utf32` from g_pSeatManager or simpler: map common keycodes to chars. updateMatches(), damage, return true.
- For proper text input, use `g_pSeatManager` xkb state to convert keycode to UTF-8. Get the keysym, convert to character with `xkb_keysym_to_utf32`. If printable (>= 32 and < 127), append to m_query.
- Return false for unhandled keys

`jumpToSelected()`:
- If m_matches empty, return
- Get the window at m_selectedIndex
- Lock the weak ref, if valid: call g_pCanvasViewport->setViewCenter(windowCenter) where windowCenter = w->m_vPosition + w->m_vSize / 2.0

`render(pMonitor, damage)`:
- If !m_active, return
- Only render on focused monitor (check pMonitor == g_pCompositor->m_lastMonitor)
- Compute overlay position: centered horizontally, 1/4 from top of monitor
- Draw background rect: CHyprColor(0.1, 0.1, 0.15, 0.9), round=8, width=OVERLAY_WIDTH
- Draw search input area: slightly lighter rect at top (OVERLAY_HEIGHT tall)
- Render query text using g_pHyprOpenGL->renderText(m_query.empty() ? "Search windows..." : m_query, textColor, 14)
- Render the text texture with renderTexture at the input area position
- For each match (up to MAX_MATCHES):
  - Draw row background, highlighted if index == m_selectedIndex (CHyprColor(0.3, 0.4, 0.7, 0.6))
  - Render match title + class with renderText, display as "Title (class)"
  - Render the text texture at the row position
