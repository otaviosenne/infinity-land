Create CCanvasMinimap class:

**src/canvas/CanvasMinimap.hpp:**
- Class with `render(PHLMONITOR, const CRegion&)` and `handleClick(const Vector2D& screenPos) -> bool`
- Private constants: MINIMAP_WIDTH=200, MINIMAP_HEIGHT=120, MINIMAP_MARGIN=16, MINIMAP_PADDING=4
- Private: `CBox minimapScreenBox(PHLMONITOR) const` — returns the screen-space box for the minimap on a given monitor
- Private: `CBox canvasBounds() const` — computes bounding box of all windows in canvas space
- Private: `Vector2D canvasToMinimap(const Vector2D& canvasPos, const CBox& canvasBBox, const CBox& minimapBox) const`
- Global: `inline UP<CCanvasMinimap> g_pCanvasMinimap;`

**src/canvas/CanvasMinimap.cpp:**

`canvasBounds()`: iterate g_pCompositor->m_windows, skip hidden/unmapped, use w->m_vPosition and w->m_vSize to compute min/max bounding box. Add 200px padding on all sides.

`minimapScreenBox(pMonitor)`: return CBox at bottom-right of monitor: `{pMonitor->m_position.x + pMonitor->m_size.x - MINIMAP_WIDTH - MINIMAP_MARGIN, pMonitor->m_position.y + pMonitor->m_size.y - MINIMAP_HEIGHT - MINIMAP_MARGIN, MINIMAP_WIDTH, MINIMAP_HEIGHT}`.

`canvasToMinimap()`: linear mapping from canvas bounding box to minimap box, preserving aspect ratio. Fit the canvas bbox inside minimap with uniform scale, centering the shorter axis.

`render()`:
1. Compute canvasBBox and minimapBox
2. If no windows, return early
3. Draw semi-transparent dark background rect (CHyprColor(0.1, 0.1, 0.1, 0.7)) with round=6
4. For each mapped, non-hidden window: map its canvas-space box to minimap coords, draw a filled rect with CHyprColor(0.4, 0.6, 0.9, 0.8) and round=2
5. Draw the current viewport rectangle: compute the screen corners in canvas space via screenToCanvas for (0,0) and (monitorSize), map those to minimap coords, draw a semi-transparent white outline rect CHyprColor(1.0, 1.0, 1.0, 0.3) with round=1

`handleClick(screenPos)`:
1. Get the focused monitor from g_pCompositor
2. Compute minimapBox for that monitor
3. If screenPos is not inside minimapBox, return false
4. Reverse-map click position from minimap coords to canvas space using canvasBounds
5. Call `g_pCanvasViewport->setViewCenter(canvasTarget)` (add this method — see below)
6. Return true

**src/canvas/CanvasViewport.cpp:**

`setViewCenter(canvasPos)`:
- Get focused monitor size from g_pCompositor
- Set m_offset so that canvasPos appears at screen center: `m_offset = monitorCenter - canvasPos * m_scale;`
- Call damageAllMonitors()

`zoomToFit(canvasBox)`:
- Get focused monitor from g_pCompositor
- Compute scale to fit: `newScale = min(monitorSize.x / canvasBox.w, monitorSize.y / canvasBox.h) * 0.9` (0.9 for padding)
- Clamp newScale to [MIN_SCALE, MAX_SCALE]
- Set m_scale = newScale
- Compute offset to center the box: `m_offset = monitorCenter - (canvasBoxCenter * m_scale)`
- Where monitorCenter = monitor->m_position + monitor->m_size / 2.0 and canvasBoxCenter = {canvasBox.x + canvasBox.w/2, canvasBox.y + canvasBox.h/2}
- Call damageAllMonitors()

**src/managers/KeybindManager.cpp:**
- Add static method `canvasZoomToFit`:
  ```cpp
  SDispatchResult CKeybindManager::canvasZoomToFit(std::string args) {
      if (!g_pCanvasViewport)
          return {.success = false, .error = "Canvas viewport not initialized"};
      const auto PWINDOW = g_pCompositor->m_lastWindow.lock();
      if (!PWINDOW)
          return {.success = false, .error = "No focused window"};
      g_pCanvasViewport->zoomToFit(CBox{PWINDOW->m_vPosition, PWINDOW->m_vSize});
      return {};
  }
  ```
